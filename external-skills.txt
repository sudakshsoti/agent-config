# external-skills.txt — skill names shipped by BARE `external` lines in
# plugins.txt (no allowlist, so the names are unknowable without a clone).
# scripts/lint-skills.py reads this so CI, which has no vendor/ checkout, can
# still tell a real vendored skill from a typo. One name per line; `#` starts a
# comment. A name here must be that skill's frontmatter `name:` (what install.sh
# links), not its directory. Names that plugins.txt already allowlists, or that
# a cloned vendor/ reveals, need no entry.
#
# Each source has a section headed by a `# <owner/repo>[:<subdir>]` comment (the
# plugins.txt source token). When a bare line's upstream adds or renames a
# skill, update that section. A reference to a skill listed nowhere still fails
# the lint. Where vendor/<slug> is cloned, the lint compares that source's
# section with the names the clone really ships and fails on any difference, in
# either direction; CI has no clone, so it cannot catch drift (run the lint with
# vendor/ present to refresh this file).
