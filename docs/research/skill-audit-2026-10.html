Terms used on this page

You only need these seven.

Skill
A Markdown file (SKILL.md) that teaches the agent how to do one kind of task.
Description / trigger
The one-paragraph summary at the top of a skill. The agent always sees it and uses it to decide whether to open the skill. A vague description fires on the wrong tasks or not at all.
Model-invoked
The agent can start the skill on its own when the description matches.
User-invoked
Only you can start it, by typing /name. Its description is hidden from the agent, so other skills cannot hand off to it.
Context cost
Every line the agent must read takes room and attention. Lines that only matter in rare cases are better in a separate file the skill points to.
Stale reference
A pointer to a file, skill, tool or model that no longer exists.
claude.ai skills
16 skills listed in distribution.txt are also uploaded to claude.ai. There, the description is the only trigger, so description problems matter more.
