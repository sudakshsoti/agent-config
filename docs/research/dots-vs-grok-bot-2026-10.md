## Cited detail: ChatGPT tiers (all https://learn.chatgpt.com/docs/pricing unless noted)

- Free $0; **Go $8/mo** (lightweight/Codex Luna tier); **Plus $20/mo**; **Pro from $100/mo** ($100/$200/$500 plans; Ultrafast mode on Pro $500). Neither Plus nor Go gets Dots.
- Codex/Work usage is token-metered against the same allowance (Plus table: GPT-6 Astra only ~5–45 local messages/5h vs Luna 350–3,000 — Astra is the scarce resource; Pro plans currently have no five-hour limit).
- Business Standard ≈ $20–25/user/mo has Plus-level limits; Premium seats ($100/$125) remove the 5-hour cap with 5x usage (help.openai.com billing excerpts).

## Cited detail: Grok tiers (all https://x.ai/pricing and https://x.ai/bot unless noted)

- SuperGrok $30/mo is the Bot entry point and also buys Grok 4.6, Expert mode, connectors, image/video generation, higher rate limits.
- X Premium+ is **not** listed among Bot-eligible plans (eligible: paid Cursor plans, SuperGrok/Plus/Heavy, Cursor Teams, Enterprise) — Premium+ alone should be assumed insufficient [INFERENCE from omission; UNVERIFIED whether it bundles SuperGrok].
- Bot-qualifying Cursor spend need not be xAI spend at all: Cursor Pro $20/mo qualifies, which undercuts SuperGrok — but only makes sense if Cursor is wanted anyway.

## Context: Meta Muse

- Altman positioned Dots weeks after Meta's Muse ("your personal agent"); Muse topped Apple/Android app stores, "quickly outpacing the Grok Bot agentic AI offering" (https://www.nbcnews.com/tech/tech-news/openai-launches-dots-ai-agents-safety-questions-rcna600338). Muse bears on the comparison only as competitive pressure: both Dots and Bot are chasing the same always-on-agent slot Muse is currently winning on distribution. No subscription decision follows from it.

## What this means for the omp ladder [INTERPRETATION, not sourced]

- The adversary/reviewer/advisor roles want cross-lineage hostility toward Claude plans. Either supplemental sub supplies that (GPT-6/Astra via ChatGPT, Grok 4.6 via SuperGrok), but subscription chat access ≠ harness API access: prior repo research found no OpenAI page authorising third-party harnesses to consume a ChatGPT plan (docs/research/openai-codex-models-2026-09.md:42). In-harness use of either family is API-metered spend, not plan usage — verify current OMP provider auth before assuming otherwise.
- Scout/smol/commit/sonic/research (cheap/fast) are unaffected by this choice: both vendors' cheap tiers (Luna, Grok mini-class) are API-side, and Claude stays default.
- Price floor for the *agent product itself*: $30/mo (SuperGrok + Bot) vs $100/mo (Pro 100 + Dots). A $20 Plus sub buys GPT-6 models for chat/Codex but no always-on agent.
- Capability lean: Dots is the deeper coding delegate (native Codex delegation, repo-aware cloud envs) on the frontier coding model (Astra); Bot is the cheaper multi-teammate system with the more open platform story (Linux builds, shared persistent computer) but a thinner documented coding path and a beta label since 2026-08-11.
- If the single factor is "always-on agent cheapest": SuperGrok. If it is "strongest coding agent to pair against Claude plans": Pro 100 + Dots, at 3.3x the price.
