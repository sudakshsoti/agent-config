# Merge

Land the pull request for the current branch — after confirming it's actually
ready.

## 1. Find the PR

`gh pr view --json number,title,state,mergeable,isDraft,baseRefName`. If there
is no PR for this branch, stop and point the user at `/pr`. If it's still a
draft, ask whether to mark it ready first.

## 2. Confirm it's ready

- **CI:** `gh pr checks`. If checks are failing or still running, surface that
  and get an explicit go-ahead before merging past red or pending checks.
- **Mergeable:** if `mergeable` is `CONFLICTING`, stop — the branch needs a
  rebase/merge from base first; don't try to force it through.

## 3. Merge

Default to **squash** — it keeps the base branch history linear and lets the
single squashed commit carry a clean house-style message. Override when the
user asks ("merge commit" → `--merge`, "rebase" → `--rebase`).

```bash
gh pr merge --squash --delete-branch
```

For a squash merge, set the resulting commit's subject/body in house style
rather than accepting GitHub's autogenerated concatenation. `--delete-branch`
removes the merged branch (remote and local); confirm that's wanted.

- **From a worktree:** gh's post-merge cleanup fails outright. It tries to check
  out the base branch and hits `fatal: 'main' is already used by worktree at
  <main clone>`, so the whole command exits non-zero. That exit code does **not**
  mean the merge failed — the server-side merge and the remote branch deletion
  have already succeeded. Confirm with `gh pr view --json state,mergedAt` before
  moving on, and let step 4 clean up the local side.

## 4. Land clean

Where you are decides how this ends. Compare `git rev-parse --show-toplevel`
against the first entry of `git worktree list --porcelain` — that first entry is
always the main clone.

- **Main clone:** switch to the base branch and fast-forward it:
  `git checkout <base> && git pull`.
- **Linked worktree:** don't run `git checkout <base>` — git refuses a branch
  already checked out in the main clone, and `git worktree remove` refuses the
  worktree you're standing in. Run `wtdone` instead: it cds to the main clone,
  confirms the branch really landed (squash merges included), removes the
  checkout, then deletes the branch. It won't close the Herdr workspace from a
  non-interactive shell — that would kill this session — so pass on the
  `herdr workspace close <id>` line it prints.

Report the merged PR number, and whether the branch alone or the whole worktree
was removed.
