# Quiet catalogue reference

Primary reference: the Met's collection search with its search bar, filter row, results count and the first two rows of the results grid. Four companion crops show object cards with category tags (Wellcome Collection), event cards with status marks (Wellcome Collection home), a search header with facet links and a masonry grid (Letterform Archive), and full-bleed dark story tiles with overlaid captions (Rijksmuseum).

All five were user-supplied full-page captures from Chrome at 2× device pixel ratio, 1683 CSS px wide, cropped to a 1200 CSS px band (850 for the Letterform Archive) and downscaled to CSS pixels on 2026-09-14. Values below were measured from the crops and are approximate.

## Borrow

One shared left and right edge for every row of the page; a search bar, filter row and results count stacked above the grid with nothing between them; image tiles in a flat pale box with the image contained and centred; a caption stack of title, maker and date on a fixed pitch aligned to the tile's left edge; a small filled tag for the object's category or event type at the image's corner; a short coloured tab as the only section marker; one status colour used for one meaning; a large placeholder with a rule instead of a boxed input; a row of plain facet links under the search; full-bleed tiles with captions overlaid at a fixed inset and a gradient to carry them.

## Do not borrow

The institutions' wordmarks, header navigation and promotional bands; the Met's 535,870-result scale as a reason for pagination chrome; Wellcome's yellow and Rijksmuseum's orange as brand colours rather than one accent role; the tilted paper shapes behind Wellcome's objects; the Letterform Archive's unloaded tiles and pure #FF0000; the Rijksmuseum's dark gradients when the artifact's images are not dark; any of the objects, paintings and photographs themselves. The catalogue's job is to let the objects be compared, so the chrome stays flat, aligned and uncoloured.
