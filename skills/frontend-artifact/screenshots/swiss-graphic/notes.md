# Swiss graphic reference

Primary reference: the Grilli Type home page, a labelled left column beside a two-column list on a shared grid. Three companion crops show the other structures this language needs: a heading over a row of cards (Museum für Gestaltung Zürich), a four-column product grid with one accent colour (Lars Müller Publishers), and a full-bleed colour block as a section (Dinamo).

All four were user-supplied full-page captures from Chrome at 2× device pixel ratio, 1683 CSS px wide, cropped to a 1200 CSS px band and downscaled to CSS pixels on 2026-09-14. Values below were measured from the crops and are approximate.

## Borrow

A label column that names each section and is otherwise empty; lists whose rules are exactly the column width; a heading on the grid's left edge with images that start on the same edge; equal columns with a small gutter and a caption stack of three roles; a product row whose covers share a bottom line and whose text shares a top line; one accent colour reserved for actions and marks; a full-bleed colour block as a section boundary with a hard edge; a display size used once per page.

## Do not borrow

The typefaces as specimens; the museum's photographs and posters; the shop's cart, login and "NEW" badges without a shop; Dinamo's 28px body and 75ch measure for reading text; a new ground colour per section when the artifact has one subject; centred headings on a left-aligned grid; saturated colour as decoration without an information role.
