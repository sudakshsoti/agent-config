## Measured

| Relationship | Value in the reference |
| --- | --- |
| Body size and leading | about 22px serif, line-height about 1.5 (33px pitch) |
| Prose measure | 600px from x=293 to x=893, about 55ch, centred |
| Prompt line | the question in bold serif at body size, in the essay's one highlight colour (yellow), 30px below the paragraph |
| Controls | "SKIP TO RESULTS" and "START" as 32px-tall rectangular buttons, uppercase sans at about 13px with 0.06em tracking, no radius |
| Figure | the interactive field is the same 600px as the prose; a small uppercase label "MOVE: 1" at 12px sits 16px above it |
| Spacing | 30px between prose and prompt, 20px prompt to button, 40px button to figure |
| Colour | near-black ground, off-white text, yellow highlight, one green field; nothing else |

## Borrow

Prose and figure sharing one measure; a single highlighted question that the next figure answers; a labelled interactive field with a single primary action and an escape hatch; small uppercase labels only on figure furniture.

## Do not borrow

The homepage archive grid, the playful logo, the dark palette as a default, or bright colour blocks used mechanically. Visual devices must clarify the argument or the navigation.
