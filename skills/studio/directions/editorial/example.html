01 / Thesis

One screen-first reading system keeps prose stable while evidence changes form around it.

This direction supports reports, essays, culture writing, and data journalism through sustained prose, comparison tables, figures and captions, annotations, and measured data.

Prose stays stable while evidence changes form around it.

Use the system when a reader needs to stay with an argument, inspect its evidence, or move between prose and data without changing the page's basic grammar. It does not create separate density presets. The reading system stays stable; the evidence mode changes around the reading column.

Four supported composition modes

Reports, essays, culture writing, and data journalism. The example is an English/Latin proof specimen, with the publication first and its inspectable appendix second.

03 / Rhythm

Text-derived rhythm starts with one 30px body line box

The body line box is 19px × 1.57895 = 30px. The middle spacing values are half a line, three quarters, one line, and one and a half lines.
