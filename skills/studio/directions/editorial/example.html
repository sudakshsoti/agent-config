Comparison

The four directions

Each direction is measured against a real reference: Ramp for instrument, Linear for product-dark, The New Yorker for editorial, Headspace for calm. There is no default, so the direction is asked for or proposed before anything is built.

Ground, character and fit. This fact set is identical across all four direction examples.
DirectionGroundCharacterSuits
editorial light paper two families, no negative tracking, almost no radius long reads, essays, explainers, reports
instrument white one grotesque, one accent, bordered cards, zero shadow pricing, comparisons, technical product pages
product-dark near-black alpha-tint elevation, white-alpha hairlines, tight tracking developer tools, dashboards-as-marketing
calm warm off-white one family, large flat colour fields, large radii consumer, wellbeing, onboarding, anything friendly

None of the measured references uses blur for elevation. Ramp uses a 1px border and no shadow, Linear uses 0 0 0 1px and 0 0 0 2px rings, V7 uses nothing, and this direction's own reference has none in its article shell. The agent default of 0 4px 6px rgba(0,0,0,0.1) matches none of them, which is why it is on the anti-pattern list.

Type

Font policy

The policy is a blacklist, so the interesting question is never which face is allowed. It is which faces are on the machine, and whether the artifact is going anywhere.

  • Blacklist, not whitelist. Twenty families are banned outright and everything else is available. The list grows over time; it is never inverted into a shortlist of approved faces.
  • Inter is body and UI only, never display. Inter at 72px in a hero is the loudest signal that an agent made the page.
  • Licensing is asked once, in the brief. "Free fonts (safe to share) or your licensed set (this machine only)?"

This direction takes Source Serif 4 for display, Hanken Grotesk for body and labels, and IBM Plex Mono for code. Two families, plus a mono that only ever sets code. Every measured reference keeps to one family or two.

This direction

The signature move

The standing rule, with the label in the margin. Every section opens with a hairline across the full width. Below it the category sits in the left rail, right-aligned against the gutter, so it reads as a margin note rather than a label stuck on top of a heading. The heading hangs in the content column at up to 42px, weight 400, tracking zero. Under 840px the rail closes and each label sits directly above its heading.

It is the reference's twelve-column grid, which starts its content at column 3 and spans 8, reduced to two columns: a rail and the measure. The page gets an asymmetric left edge and a visible sense of margin without a single box, card or coloured band.

Radius

Four tokens, two of them zero

Radius is the exception in this direction rather than the default, so two of the four tiles below are square. Judge whether either non-zero token is doing anything the hard corner beside it was not already doing.

--radius-sm · 0 · inert by design: the default corner is square

--radius-md · 0 · inert by design: the default corner is square

--radius-lg · 4px · the table container only

--radius-pill · 999px

--radius-sm and --radius-md are two tokens refusing the same thing, and they stay separate rather than collapsing because a consumer swapping another direction's tokens.css in has to overwrite both. Reaching for a rounded corner means typing a different token name and noticing that you did. --radius-lg is the reference's own 4px table container, which the composed page above uses once, and --radius-pill comes from its 64px sticky utility bar, the one place that page lets a control round.

Never round a panel, a section, an image, a table cell or a code block. Four rounded corners on a panel turns a printed page into an app screen, which is a different direction's job.

Elevation

Four tiles: a filled sunk field, the shadow token applied to a second copy of it, and the two rule weights that carry the work instead. Judge whether the page reads as one sheet with fields cut into it rather than as cards sitting above it.

What carries depth instead is recession and vertical space. The three grounds are fields cut into the same sheet and nothing ever sits above it, which is why --shadow-1 is declared as none rather than left out: a consumer swapping another direction's tokens.css in has to overwrite it.

Panels and features

Two rule weights

--hair at 1.44:1 for repeated separation, --ink-3 at 3.11:1 for the two divisions with structural weight. A view carries no third weight.

Two families

Source Serif 4 for display at weight 400, Hanken Grotesk for body and every label, and IBM Plex Mono for the code block and nothing else.

Departure three

The accent is darkened. The reference's action blue #0879bf reaches 4.31:1 against this paper rather than the 4.69:1 it gets against #fff, so it fails AA for body text as a link colour. oklch(0.510 0.128 245.4) holds the measured hue and reaches 5.26:1.

Departure five

The ground ladder's deepest step is pushed down. Matching the measured #e5e5e5 border tier put --ground-3 only 1.09:1 from --ground-2, which is two sunk fields nobody can tell apart, so the tier was given up and the separation kept at 1.15:1.

Procedure, caveat and the calls to action

  1. Ask for the direction, or propose one. There is no default, and the four are not interchangeable.
  2. Build one self-contained HTML file against that direction's tokens.css and DESIGN.md.
  3. Render it at 390 by 844 and 1440 by 900, then score it against the direction's own avoid list.
  4. Revise once below 80, and render again before handing it over.
  • A card grid standing in for a comparison is out. Four items with four attributes each is a table, and a grid of panels costs the reader the ability to compare down a column.
  • Centred prose is out. The left rail exists to break the symmetry, and a centred column with centred headings throws away the one structural idea the direction has.

Visual complexity follows informational complexity. A 400-word note gets a header, prose, and nothing else — the specimen sheet below the masthead is long because there are 40 tokens to account for, not because length is a virtue.
