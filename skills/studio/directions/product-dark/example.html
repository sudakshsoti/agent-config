Near-black ground, hairline rings for depth, no blur anywhere.

See the render gate Compare directions

Studio builds one self-contained HTML artifact against a named design direction, renders it at 390 and 1440, scores it, and revises once before handing it over.

The direction decides everything a browser can see. Its tokens.css is copied into the artifact unedited and every rule below it is authored against those custom properties, so a colour or a size that a token already covers never gets written twice.

Four directions

One brief, four grounds

Each direction is measured against a named reference rather than copied from one, and each carries its own avoid list. Sixty of the gate's hundred points ride on that list.

Direction Ground Character Suits
editorial light paper two families, no negative tracking, almost no radius long reads, essays, explainers, reports
instrument white one grotesque, one accent, bordered cards, zero shadow pricing, comparisons, technical product pages

Forty points are universal: hierarchy, measure and vertical rhythm, colour discipline, integrity at 390, and zero anti-pattern hits. The remaining sixty are the direction's own avoid list, scored as the share of its items respected. Below eighty, or on any failing check, the artifact gets one revision and both commands run again. A second failure ships, with every failing check named out loud.

Font policy

Blacklist only

Twenty families are banned outright and everything else is available. The list grows over time; it is never a shortlist to pick from.

Inter carries body and UI, never display. Inter at 72px in a hero is the loudest an agent made this signal there is. This direction's reference gives its own display role to Inter, and this direction hands it to Geist instead.

  • Display Geist at 500, inside the 300 to 510 band every measured reference uses. The reference's own h1 sits at 510.
  • Body and UI Inter at 400, 16px on a 24px line, tracking left alone.
  • Mono JetBrains Mono, the free stand-in that keeps the file shareable. Code, eyebrows and badge labels only.

Signature move

Elevation is a ring, not a blur

Not one of the seven measured references uses blur for elevation. Ramp holds a 1px border and no shadow, this direction's reference stacks 0 0 0 1px and 0 0 0 2px alpha rings, V7 uses nothing, and the New Yorker's article shell has none. The agent default 0 4px 6px rgba(0,0,0,0.1) matches none of them.

The lift comes from a tint instead. Composite the reference's own rgba(255,255,255,0.01) over its #101112 and the result is #121314, which is the next rung it already ships. The tints are not a layer on top of the ladder, they are the ladder, so a raised surface is one step up and the ring only has to draw the edge a border would have drawn.

Tracking separates the measured references further than their typefaces do:

  • New Yorker, normal at 42px.
  • Ramp, −0.01px at 64px.
  • This direction's reference, −0.022em.
  • V7 and Headspace, −0.03em.

So the ring holds the depth and the tracking holds the temperature. Loosen the headings past −0.01em and this stops being a product page, whatever the shadows are doing.
