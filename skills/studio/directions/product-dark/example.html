studio

Near-black ground, hairline rings for depth, no blur anywhere.

See the render gate Compare directions

Studio builds one self-contained HTML artifact against a named design direction, renders it at 390 and 1440, scores it, and revises once before handing it over.

The direction decides everything a browser can see. Its tokens.css is copied into the artifact unedited and every rule below it is authored against those custom properties, so a colour or a size that a token already covers never gets written twice.

Four directions

One brief, four grounds

Each direction is measured against a named reference rather than copied from one, and each carries its own avoid list. Sixty of the gate's hundred points ride on that list.

Direction Ground Character Suits
editorial light paper two families, no negative tracking, almost no radius long reads, essays, explainers, reports
instrument white one grotesque, one accent, bordered cards, zero shadow pricing, comparisons, technical product pages
product-dark this page near-black alpha-tint elevation, white-alpha hairlines, tight tracking developer tools, dashboards-as-marketing
calm warm off-white one family, large flat colour fields, large radii consumer, wellbeing, onboarding, anything friendly

Forty points are universal: hierarchy, measure and vertical rhythm, colour discipline, integrity at 390, and zero anti-pattern hits. The remaining sixty are the direction's own avoid list, scored as the share of its items respected. Below eighty, or on any failing check, the artifact gets one revision and both commands run again. Font policy

Blacklist only

Twenty families are banned outright and everything else is available. The list grows over time; it is never a shortlist to pick from.

Geist carries display, body and UI. This direction used to hand body to Inter and keep Geist for display, which spent a family on a distinction no reader could see: two neo-grotesques with near-identical metrics read as one family set inconsistently. Dropping the second family also removes the failure mode the reference invites, since the reference gives its own display role to Inter.

  • Display Geist at 500, inside the 300 to 510 band every measured reference uses. The reference's own h1 sits at 510.
  • Body and UI Geist at 400, 16px on a 24px line, tracking left alone.
  • Mono JetBrains Mono, the free stand-in that keeps the file shareable. Code, eyebrows and badge labels only.

Signature move

Elevation is a ring, not a blur

Not one of the seven measured references uses blur for elevation. Ramp holds a 1px border and no shadow, this direction's reference stacks 0 0 0 1px and 0 0 0 2px alpha rings, V7 uses nothing, and the New Yorker's article shell has none. The agent default 0 4px 6px rgba(0,0,0,0.1) matches none of them.

The lift comes from a tint instead. Composite the reference's own rgba(255,255,255,0.01) over its #101112 and the result is #121314, which is the next rung it already ships. The tints are not a layer on top of the ladder, they are the ladder, so a raised surface is one step up and the ring only has to draw the edge a border would have drawn.

Tracking separates the measured references further than their typefaces do:

  • New Yorker, normal at 42px.
  • Ramp, −0.01px at 64px.
  • This direction's reference, −0.022em.
  • V7 and Headspace, −0.03em.

So the ring holds the depth and the tracking holds the temperature. Loosen the headings past −0.01em and this stops being a product page, whatever the shadows are doing.

Radius

Four steps, never uniform

Four samples off the measured 2 / 4 / 6 / 8 / 12 / 16 ramp, each on a raised tile, so the question is whether any two corners in one view are the same.

--radius-sm 4px. Inline code, small fills, anything under about 2rem tall.
--radius-md 8px. The working radius: panels, table shells, code blocks.
--radius-lg 12px. The widest surfaces only, a figure or a full-width note.
--radius-pill 9999px. Buttons and badges, matching the measured button exactly.

None of the four is zero, and none of them repeats: if four things in one artifact all want 8px, three of them are the wrong size for it.

Elevation

A ring, never a blur

Four rungs of one ladder: the page itself, a flat container fenced on it, the nearer tint every hovered and pressed state takes, and the raised surface that adds the rings.

--ground No fill of its own and no edge. The page, and the fill a chip cuts down to when it sits on a nearer surface.
--ground-2 with a 1px --hair border and box-shadow: none. Flat, fenced on the ground rather than lifted off it.
--ground-3 alone, with no ring. The nearer tint: hover, pressed, a table's header row, a badge fill. One signal per event.
--shadow-1 over --ground-3, and no border at all, because the ring is the border.

--shadow-1 is 0 0 0 1px oklch(0 0 0 / 0.2), 0 0 0 2px oklch(0 0 0 / 0.1), inset 0 0 0 1px oklch(1 0 0 / 0.04): two outer alpha rings darkening the seam where the surface meets the ground, one inset hairline drawing the surface's own top edge, and a blur radius of zero on all three. There is one shadow token because there is exactly one raised tier, and a pressed control moves to --ground-3 rather than taking a second one.

The tint and the ladder are the same mechanism, which is the finding this direction is built on. --ground-3 sits 1.11:1 in fill above --ground-2, one step past the measured #161718, and that is the smallest step here that survives a phone held at arm's length in daylight.

  • Flat tables, code blocks, notes, and the resting fill of a ghost control.
  • Raised one tint up and ringed, never nested inside another raised surface.
  • Neither the rail, which is chrome rather than a surface: no fill, no ring, separated from the content by space alone.

Panels in a grid

2px

On a near-black ground a 2px corner is indistinguishable from a rendering artefact, so it spends a token on nothing.

6px

16px

Feature blocks

Two families, not three. Geist carries display, body and UI, and JetBrains Mono carries literals. One accent, spent three times. The primary button fill, links in prose, and the focus-visible ring. Never a heading, never a border, never a section background, and never a second hue for a secondary state, because a ghost button on --hair is the secondary state.
