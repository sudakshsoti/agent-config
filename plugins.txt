# plugins.txt — declarative plugin manifest, applied by install.sh.
#
# install.sh reads this and runs `claude plugin marketplace add` +
# `claude plugin install` for each line, so a fresh machine reproduces the
# plugin set. Both commands are idempotent (no-op if already present).
#
# We do NOT vendor plugin content — it's large, owned upstream, and
# auto-updates from its marketplace. This file tracks only *which* plugins,
# at floating (latest) versions. To reproduce an exact version, install the
# tag by hand; this manifest intentionally tracks latest.
#
# Format (one directive per line; blank lines and #-comments ignored):
#   marketplace <github-repo-or-url>     # `claude plugin marketplace add <src>`
#   plugin      <name@marketplace>       # `claude plugin install <name@mkt>`
# Marketplaces must be listed before the plugins that come from them.

# External skill sources — `external <owner/repo>`, applied by install.sh step 1c.
#
# NOT a plugin, and cannot be one: emilkowalski/skills ships no
# .claude-plugin/marketplace.json, so `claude plugin marketplace add` fails
# outright. Even if it did, a Claude plugin is visible to Claude alone —
# Codex, opencode and omp read ~/.agents/skills and know nothing about
# plugins. `external` covers both gaps: install.sh clones the repo to
# vendor/<owner>-<repo>/ (gitignored) and symlinks each of its skills into
# ~/.claude/skills AND ~/.agents/skills, exactly like a repo-owned skill.
#
# Vendored by reference, not copied — upstream files never enter this repo's
# history, so they skip scripts/lint-skills.py and need no dist/<name>.zip.
# Re-running install.sh fast-forwards each clone, so these track latest.
# A repo-owned skills/<name> always shadows an external skill of the same name.
#
# emil's 12 design-engineering skills: animate, animate-expo,
# animation-vocabulary, apple-design, ask-sonner, emil-design-eng,
# find-animation-opportunities, improve-animations, pick-ui-library,
# prototype, review-animations, write-swift. The last four carry
# `disable-model-invocation: true` — slash-command only, invisible to the
# model's skill list by design.
external emilkowalski/skills
