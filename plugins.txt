# plugins.txt — declarative third-party skill-source manifest, applied by install.sh.
#
# This file declares third-party SKILL sources only. There is no plugin or
# marketplace directive any more: install.sh targets OMP and Pi, and neither has
# a plugin CLI. Every source here is vendored by reference and linked into the
# shared ~/.agents/skills root, so one link reaches both harnesses.
#
# Format (one directive per line; blank lines and #-comments ignored):
#
#   external <owner/repo>[:<subdir>] [skill ...]
#
# install.sh clones each source into vendor/<owner>-<repo>/ (gitignored) and
# fast-forwards it on each run, so these track latest. The optional :<subdir>
# pins which tree to read when a repo ships several copies. Naming individual
# skills after the directive links only those — a bare repo links every skill it
# ships, which consumes the shared context budget and is only right for a small,
# curated collection.
#
# Name collisions (two sources shipping the same skill name) resolve by fixed
# precedence, stated in AGENTS.md (Skills). Two allowlists naming the same skill
# are rejected by scripts/check-manifest.py.
#
# Vendored by reference, never copied: upstream files do not enter this repo's
# history and are not linted by scripts/lint-skills.py.
#
# To disable a source, comment out its line and re-run `./install.sh --prune`,
# which clears the links it left in ~/.agents/skills.

# mattpocock/skills — every bucket (user decision 2026-10-04). Each bucket is
# its own line because the installer reads one directory level per source.
# `deprecated` is omitted: upstream keeps it empty. `in-progress` is beta and
# upstream says its skills may change or vanish without warning. A repo-owned
# skills/<name> wins a name collision, so upstream `handoff` and `pr` are
# shadowed by ours, and upstream `prototype` by emilkowalski's line above
# (install prints a SKIP warning for each). Model-invocable skills in these
# buckets add to the always-loaded skill list; user-invoked ones
# (`disable-model-invocation: true`) do not.

external mattpocock/skills:skills/productivity
external mattpocock/skills:skills/misc
external mattpocock/skills:skills/in-progress

# jakubkrehel/skills (interfaces.dev) — allowlisted to the three upstream skills
